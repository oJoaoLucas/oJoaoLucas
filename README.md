### Projetos

**Jura Auto Center — sistema de gestão**\
Sistema próprio da oficina, que substituiu o ERP antigo: ordem de serviço, orçamento, estoque, clientes e relatórios. Migração de mais de 18 mil ordens de serviço do sistema anterior, integração de nota fiscal por API, painel em tempo real na TV da oficina e mais de 400 testes automatizados.\
Next.js · TypeScript · Supabase (PostgreSQL, RLS, Realtime) · Vercel · Raspberry Pi

**Jura Auto Center — atendimento no WhatsApp**\
Bot de triagem no número oficial da oficina: entende texto, áudio, foto e PDF, agrupa mensagens em sequência, coleta os dados do cliente e passa o atendimento para a equipe. Regras em TypeScript com testes e alerta na recepção quando o bot para.\
Evolution API · n8n · Claude API · OpenAI API · Supabase · Redis · Docker

**Jura Auto Center — elevadores com câmera e IA**\
Lê o vídeo do DVR da oficina, identifica se cada elevador está ocupado e qual é o carro, e atualiza o sistema sozinho. Um banco de fotos local aprende com cada correção da equipe e reduz o uso da IA paga.\
Python · RTSP/ffmpeg · Claude API · DINOv2 (embeddings em GPU) · API REST no sistema de gestão

**Jura Auto Center — site e landing pages**\
Site institucional da oficina, com páginas por serviço, SEO local e landing de pneus com formulário de orçamento.\
Next.js · React · TypeScript · Tailwind CSS · Motion · juraautocenter.com.br

**Aplicativo de organização da vida em casal**\
Agenda compartilhada, recados, treinos, finanças com divisão proporcional e metas, tarefas da casa, receitas e lista de mercado, viagens e listas de filmes e séries, com os módulos ligados entre si. Instalável no celular, com login por biometria, notificações push, tarefas agendadas e integração com o Home Assistant.\
React · Vite (PWA) · Node.js · Supabase (PostgreSQL com RLS, pg_cron) · WebAuthn · Web Push

**Titans Araras**\
Gestão do time de vôlei Titans Araras: atletas, chamada, mensalidades, relatórios e inscrição online, com atualização em tempo real e exportação em CSV, Excel e PDF.\
Next.js · React · TypeScript · Tailwind CSS · shadcn/ui · Supabase (Realtime) · voleititansararas.com.br

**Moedin.IA**\
Assistente financeiro pessoal: gastos registrados pelo WhatsApp em texto, áudio ou foto de comprovante e acompanhados num painel web. TCC desenvolvido em equipe.\
Next.js · Supabase · n8n · Evolution API · Claude API · OpenAI API · moedin-ia.com.br
